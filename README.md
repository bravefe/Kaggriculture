# [Kaggriculture](https://www.kaggle.com/competitions/kaggriculture)

## Virtual Environment
Plese use python **3.11** if not 3.12.

สร้าง venv
```bash
python -m venv .venv
```
activate the venv
```bash
.venv\Scripts\activate
```
Then, run this to install all the lib.
```bash
pip install -r requirements.txt
```
