# [Kaggriculture](https://www.kaggle.com/competitions/kaggriculture)

### Virtual Environment

run this to สร้าง venv
```bash
python -m venv .venv
```
activate the venv
```bash
.venv\Scripts\activate
```
Then, run this to install all the lib.
```bash
pip install -r requirements.txt
```
